# Консольна RPG
Створіть окрему БД SQL Server і виконайте `schema.sql`. Задайте рядок підключення у `MYSTAT_GAME_SQL`, далі `dotnet run`. Пороги досвіду 100, 200, 400… XP зберігається як залишок до наступного рівня. Запити на персонажів обмежені власником, паролі зберігаються з PBKDF2 і випадковою сіллю.
