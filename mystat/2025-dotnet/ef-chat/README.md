# Консольний чат C# / EF Core
Локальний TCP-сервер і консольний клієнт. Встановіть змінну `MYSTAT_CHAT_ADMIN_PASSWORD` із власним паролем (мінімум 8 символів), потім запустіть `dotnet run -- server` і в іншому терміналі `dotnet run -- client`. Початковий адміністратор — `admin`. Адміністратори можуть створювати клієнтів і адміністраторів та видаляти клієнтів. Обидві ролі можуть надсилати повідомлення і читати останні 20 записів. У SQLite є окремі таблиці адміністраторів, клієнтів і повідомлень. `chat.log` фіксує час збереження повідомлення без паролів або вмісту.

Сервер слухає тільки 127.0.0.1, тому клієнт запускається на тому самому ПК.
