# Міністанція мікроклімату

Проєкт для Wokwi: Arduino Mega, DHT22, I²C LCD1602, перемикач, два світлодіоди через резистори 220 Ω та два сервоприводи. Відкрийте новий Arduino Mega у Wokwi й замініть `sketch.ino` та `diagram.json`; додайте залежності з `libraries.txt`.

В одному положенні перемикача LCD показує температуру, в іншому — вологість. Для перевірки змініть значення у вікні DHT22: при 28 °C або вище вмикається червоний LED і повертається вентилятор, при 65% або вище — синій LED і заслінка. `presentation.html` відкривається в браузері і керується стрілками.
