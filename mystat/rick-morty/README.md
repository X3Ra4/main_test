# Випадковий персонаж з Rick and Morty

`npm install` → `npx expo start`. При відкритті з’являється випадковий персонаж. «Далі» робить нову вибірку. Фільтри застосовуються на сервері, а в історії зберігаються до восьми різних персонажів. Перевірте статус «Живий» та вид `Human`, очищення фільтрів, лічильник і відкриття мініатюри без повторного запиту.
