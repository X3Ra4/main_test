# Книжкова полиця

Мобільний каталог для читачів. Пошук книжок за назвою або автором, опис і обкладинка, три власні полиці, прогрес читання, нотатки та статистика профілю. Дані зберігаються на пристрої через AsyncStorage.

## Запуск

`npm install`, потім `npx expo start`. Відкрийте застосунок в Expo Go або натисніть `w` для браузера. Змінні оточення не потрібні. Дані надає [Open Library](https://openlibrary.org/developers/api).

## Перевірка

1. Знайдіть книжку за назвою, наприклад «Hobbit», а потім оновіть список жестом.
2. Відкрийте деталі, виберіть полицю «Читаю», введіть сторінку і нотатку та збережіть.
3. На вкладці «Мої полиці» перевірте, що після перезапуску запис залишився.
4. Відкрийте книжку, змініть статус на «Прочитано» та подивіться, як змінюється шкала у профілі.
5. Введіть ім’я й перевірте перехід на полиці після збереження.
6. Для перевірки порожнього результату введіть запит без збігів. Для перевірки помилки вимкніть мережу, поверніть її та натисніть «Повторити».

## Навігація

Пошук, полиці та профіль — окремі вкладки. Деталі відкриваються поверх вкладок за ідентифікатором твору. Анімації використовуються для появи результатів, реакції кнопок та оновлення шкали прочитаного.
