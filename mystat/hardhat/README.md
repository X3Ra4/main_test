# Dutch Auction і Voting

`npm install`, потім `npm run test:auction` для ДЗ №6 і `npm run test:voting` для фінального проєкту. Усі тести — `npm test`. Для локального деплою запустіть `npx hardhat node`, а в іншому терміналі — `npm run deploy`.

**DutchAuction.** Ціна спадає щосекунди. Перша покупка закриває аукціон перед переказами, продавець отримує ціну лота, покупець — переплату. Продавець може закрити прострочений аукціон без покупки.

**Voting.** Власник реєструє кандидатів, кожна адреса має один голос. Після дедлайну доступний підрахунок переможця. Нічия або відсутність голосів повертають зрозумілу помилку. Правило працює на рівні адрес, тож одна людина з кількома адресами потребувала б окремої перевірки права голосу в реальному застосунку.
