# Адаптивна сторінка книжкової майстерні

Самостійний приклад адаптивної верстки з Flexbox і Grid. Відкрийте `index.html`. Перевірте ширину 375, 768 і 1280 px: сітка переходить від однієї до трьох колонок, навігація переноситься, горизонтального прокручування немає. Для внесення змін саме до сайту з аудиторії потрібні його вихідні файли.
