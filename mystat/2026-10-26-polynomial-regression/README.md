# Поліноміальна регресія та регуляризація

`python -m pip install numpy scikit-learn`

`python main.py`

Перший запуск завантажує California Housing через `fetch_california_housing`. Програма виводить тестове R² квадратичної моделі, порівняння трьох ступенів полінома, коефіцієнти Lasso та таблицю порівняння Ridge зі звичайною регресією. У всіх порівняннях використовується той самий поділ 80/20 з `random_state=42`.
