# Лінійна регресія через градієнтний спуск

Запуск: `python -m pip install numpy`, потім `python main.py`.

Дані [Housing з пакета Ecdat](https://vincentarelbundock.github.io/Rdatasets/doc/Ecdat/Housing.html). Ціль — `price`. Модель використовує три числові ознаки та дві бінарні категоріальні. Параметри стандартизації обчислюються на навчальних даних. Перший стовпець матриці відповідає вільному члену, а ваги оновлюються за градієнтом середньоквадратичної помилки.
